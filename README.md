## English 

**Simple Write** is an Obsidian-inspired Markdown note-taking application built with Tauri + Vue 3. It is designed to be lightweight, easy to install, and effortless to use.

### Features

- **Ready to Use**: No complex setup required — simply install and import a warehouse to get started.
- **Local-first**: All notes are stored locally as plain Markdown files. No internet connection required.
- **Warehouse Management**: Organize notes into independent warehouses (folders), each with its own settings.
- **Markdown Editing**: Full Markdown editing support with live preview, syntax highlighting, and rich formatting.
- **Knowledge Graph**: Visualize connections between notes with an interactive relation graph.
- **Link Management**: Create and track bidirectional internal and external links between notes.
- **Multi-language**: Supports both English and Chinese interfaces.

## 中文

**Simple Write** 是一款仿 Obsidian 开发的 Markdown 笔记软件，基于 Tauri + Vue 3 构建，主要特点是体积小、易安装、易使用。

### 功能特性

- **即装即用**：无需繁琐配置过程，简单地安装和导入仓库。
- **本地优先**：所有笔记以 Markdown 文件形式存储在本地，无需联网。
- **仓库管理**：将笔记组织为独立的仓库（文件夹），每个仓库拥有独立的设置。
- **Markdown 编辑**：支持完整的 Markdown 编辑功能，包括实时预览、语法高亮和丰富的文本格式化。
- **关系图谱**：通过交互式关系图谱，直观展示笔记之间的链接关系。
- **链接管理**：支持创建和追踪笔记之间的内部/外部双向链接。
- **多语言**：目前支持中文和英文界面。
