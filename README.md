## English 

**Simple Write** is a lightweight writing tool built with Tauri + Vue 3, supporting both Markdown notes and novel writing. It is designed to be lightweight, easy to install, and effortless to use.

### Features

- **Ready to Use**: No complex installation or configuration — just download the exe and start writing.
- **Local-first**: All files are stored locally. No internet connection required.
- **Warehouse Management**: Treat independent folders as separate warehouses, each with its own configuration.
- **Markdown Editing**: Full Markdown editing support with live preview, syntax highlighting, rich formatting, outlines, and bidirectional links.
- **Novel Writing**: Dedicated txt editing view with insert annotations, mark highlighting, hidden links, and batch export — ideal for novel and long-form writing projects.
- **Writing Structure Graph**: Hierarchical file structure graph with folder expand/collapse, horizontal/vertical layout toggle, and file relationship details.
- **Link Management**: Create and track bidirectional internal/external links between files, plus custom named links for quick navigation.
- **Quick Paste**: Paste clipboard content into files with a single click.
- **Config Profiles**: Switch between multiple named configuration profiles, each with its own theme, fonts, insert types, and mark types.
- **Multi-language**: Currently supports both English and Chinese interfaces.
- **Multiple Themes**: Light, dark, and eye-care themes with adjustable font sizes.

## 中文

**Simple Write** 是一款支持 Markdown 笔记与小说写作的轻量写作工具，基于 Tauri + Vue 3 构建，主要特点是体积小、易安装、易使用。

### 功能特性

- **即装即用**：无需繁琐安装和配置过程，下载 exe 文件即可直接使用。
- **本地优先**：所有文件均存储在本地，无需联网。
- **仓库管理**：将相互独立文件夹设为仓库，分别进行配置。
- **Markdown 编辑**：支持完整的 Markdown 编辑功能，包括实时预览、语法高亮、丰富文本格式化、大纲和双向链接。
- **小说写作**：专属 txt 编辑视图，支持插入批注、标记高亮、隐藏链接和批量导出——适合小说和长篇写作项目。
- **写作结构图**：层级文件结构图，支持文件夹展开/折叠、左右/上下布局切换、文件关系详情查看。
- **链接管理**：支持创建和追踪文件之间的内部/外部双向链接，以及自定义命名链接便于快速跳转。
- **快速粘贴**：一键将剪贴板内容粘贴到文件中。
- **配置档案**：支持多套命名配置档案切换，每套独立保存主题、字体、插入类型和标记类型。
- **多语言**：目前支持中文和英文界面。
- **多主题**：浅色、深色、护眼多种主题，字体大小可调节。
